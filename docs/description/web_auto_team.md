## 编组自动组队

将本任务放在组队配置的第一项，后面放副本、捉鬼等队长要执行的任务。同一份配置可供五个实例使用。

- 队长号：在游戏“好友 → 联系人 → 全部联系人”菜单中建立“自动组队”编组，将四名队员放进去，事先互加好友。
- 队员号：不要建立同名编组。确认完整菜单中没有该编组后，脚本自动作为队员等待并接受邀请。
- 编组名默认“自动组队”，可修改；编组只允许一个正在运行的队长。
- 等待时间默认 360 秒，可设 10～1800 秒。队长从准备邀请开始计时，反复扫描编组，只有看到“邀请入队”才点击，直到连续确认 5 名真人或超时。助战不算真人，识别失败也不会算满员。
- 队长满员后继续配置中后面的任务；队员接受邀请、确认副本准备并持续跟队。队长配置结束后，队员结束跟队，后续队长任务记为“未执行”。请把个人日常放在另一份配置中。
- 队长失败或停止后，中控通知跟队实例结束并显示原因。超时不启动后续任务，不自动踢人、退队或匹配陌生人。
- 界面识别失败会报错，不会把打不开好友页当成“没有编组”。需要横屏 16:9，运行期间不要手动切换好友或队伍窗口。

这是 Web 中控任务，原桌面入口的按姓名“邀请队员”和“队员挂机”功能保持独立。

梦幻西游 MAA Web 中控 — Windows 安装与操作说明
适用版本：本地 Web 版本（含 Windows MuMu / 雷电接入）

一、先了解这个包
这是完整项目源码和游戏识别资源的安装包，附安装、启动脚本及当前保存的 7 套任务组合。
首次安装需要联网下载 Python 依赖。Python、模拟器和梦幻西游官方游戏客户端需要另行安装；本包不是双击即用的独立 EXE，也不是离线安装包。
Windows 接入代码已通过自动化测试，尚未在 Windows 实机验收。推荐先用一个实例、一个短任务验证，再开启多实例。

二、准备 Windows 电脑
1. 建议使用 Windows 10/11 64 位、Intel / AMD 处理器。Windows ARM 未验证。
2. 安装 MuMu 或雷电，先确认模拟器能正常开机；模拟器需要的虚拟化功能按厂商安装提示配置。
3. 在每个准备使用的实例中安装梦幻西游官方手游客户端，并先手动登录账号、选择角色，确认能进入游戏场景。
4. 在模拟器设置中开启 ADB 调试。菜单位置因版本而异，请在设置中搜索 ADB 或调试；只需本机可连接。
5. 设置游戏画面为横屏 16:9，建议 1280×720，设置生效后按模拟器提示重启。

三、安装 Python（首次操作）
1. 打开 Python 官方 3.12.10 下载页：
   https://www.python.org/downloads/release/python-31210/
2. 在 Files 区域选择 Windows installer (64-bit)，安装 Python 3.12。
3. 安装时勾选 Add python.exe to PATH，保留 pip 和 Python Launcher 的安装。
4. 安装完成后打开命令提示符，输入：
   py -3.12 --version
   能显示 Python 3.12.x 即可。
5. 如果系统提示缺少 VCRUNTIME / MSVCP DLL，安装微软官方 Visual C++ x64 运行库后重试：
   https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist/
   在页面中选择 X64 下载链接。

四、解压与安装中控（首次操作）
1. 对 ZIP 点右键 → 全部解压；不要直接在压缩包预览窗口中运行脚本。
2. 将项目文件夹放到普通可写目录，例如：
   D:\MHXY\Maa_MHXY_MG
3. 进入文件夹，应能看到 setup-web.bat、start-web.bat、requirements-web.txt、web、assets、agent。
4. 双击 setup-web.bat，等待依赖安装结束。脚本会优先选择 Python 3.12，并创建本机专用的 .venv-web 环境。
5. 看到 Setup complete 表示安装完成。安装失败时保留窗口中的最后一段错误，按第十一节排查。
6. 不要将 Mac 的 Python 环境复制过来；Windows 必须在本机安装依赖。

五、带入现有的 7 套任务组合（可选，首次安装）
完整包的 presets 文件夹中有 profiles.json，包含当前保存的组合。API 密钥类字段已经清空，相关功能需在网页中重新填写。
1. 在首次启动中控之前，在项目目录下新建 .web-data 文件夹（注意开头的点）。
2. 将 presets\profiles.json 复制到 .web-data\profiles.json。
3. 启动网页后，在“任务配置”中检查组合与任务选项，再给实例选择配置。
4. 如果中控已经运行，先停止所有任务、等待账号采集结束，再到中控终端按 Ctrl+C 停止服务，然后复制文件。
5. 如果目标位置已存在 profiles.json，先备份，不要直接覆盖已有配置。覆盖会替换整个配置列表。
6. 不要复制 Mac 的 devices.json；Windows 需要重新扫描当地模拟器并绑定组合。

六、启动并打开网页
1. 双击 start-web.bat，保持打开的命令行窗口运行。
2. 浏览器打开：
   http://127.0.0.1:8000/
3. 本版本按你的设置免令牌访问，默认监听 0.0.0.0:8000。
4. 日后启动只需运行 start-web.bat，无需每次重新安装。
5. 不要同时启动两份中控。如果端口被占用，见第十一节。

七、导入 MuMu / 雷电实例
1. 网页打开“模拟器总览” → “添加模拟器”。
2. 在“模拟器类型”选择 MuMu 或雷电，点击“刷新列表”。
3. 列表支持显示未开机的实例；可以逐个“添加”或“全部添加”。
4. 没找到安装位置时，展开“模拟器安装在其他位置？”，填写安装目录或命令行工具完整路径，再刷新。
   MuMu 示例（以实际安装位置为准）：
   D:\Program Files\Netease\MuMu Player 12\nx_main\mumu-cli.exe
   也支持 MuMuManager.exe，常见于 nx_main 或 shell 子目录。
   雷电示例：
   D:\LDPlayer\LDPlayer9\ldconsole.exe
   也兼容 dnconsole.exe。
5. 命令行工具所在目录需要有模拟器自带的 adb.exe；兼容部分版本的 adb_server.exe。
6. 重复导入同一实例会保留原任务配置。移动模拟器安装目录后，需要检查路径并重新导入。
7. 使用浏览器访问 Mac 上的中控，只能扫描那台 Mac；要控制 Windows 的模拟器，必须在 Windows 上运行本中控。

八、开机、登录与执行配置
1. 在实例卡片右上角打开开关：启动指定模拟器、等待 Android 就绪、打开官方游戏并尝试进入游戏场景。
2. 首次登录、验证码、账号选择、协议确认、更新提示，需要在模拟器中手动处理；完成后重试。
3. 打开“任务配置”，可跨分类勾选多个任务、调整顺序和选项，填写名称并保存。
4. 回到实例卡片，在任务配置下拉列表选择组合，然后点“启动配置”。
5. “开机”只负责打开游戏；“启动配置”执行组合中的任务。
6. 可勾选多个实例后批量启动；每个实例使用自己的独立执行进程。
7. 点击“日志”查看步骤与错误；执行中可查看任务进度。
8. “停止”停止任务并保留模拟器；关闭实例开关会先停止该实例任务，再关闭该实例。

九、组队、账号中心与监控中心
组队：
- 队长在“好友 → 联系人 → 全部联系人”创建编组“自动组队”，将目标队员加到该编组。
- 编组自动组队放在任务组合第一项；检查编组名称、角色和等待时间等选项。
- 按现有脚本流程邀请编组中可入队的人，队员处理左侧邀请；满队或达到等待时间后按配置处理。
账号中心：
- 每个已导入实例有对应切页；先让游戏窗口运行并进入角色场景。
- 点击“采集此实例”或“采集已运行窗口”，读取角色、金币、银币、修炼和帮派技能等资料。
- 采集会操作游戏页面，期间请等待完成；未开放或未识别的数据会显示未采集或不可采集。
监控中心：
- 查看已开机实例的实时画面。使用同一实例的 ADB 连接；窗口未运行或 ADB 未开启时无法显示游戏画面。

十、局域网访问
1. 在运行中控的 Windows 电脑上按 Win+R，输入 cmd，运行 ipconfig。
2. 找到当前联网网卡的 IPv4 地址，例如 192.168.1.20。
3. 同一局域网内的手机或电脑打开：
   http://192.168.1.20:8000/
   这里必须换成 Windows 电脑自己的 IP；其他设备不能使用 127.0.0.1。
4. 本机能打开但其他设备打不开时，检查 Windows 防火墙是否允许项目 Python 在专用网络接收入站连接，以及路由器是否开启了设备隔离。
5. 当前无需令牌；保持在自己的局域网内使用，无需配置路由器端口转发。

十一、常见问题
A. “py 不是内部或外部命令”：
   重新检查 Python 3.12 和 Python Launcher 是否安装，安装后重新打开命令行。
B. pip 下载超时 / 安装失败：
   检查网络后重新运行 setup-web.bat；不要删除 assets 或修改系统 Python。保留错误信息便于排查。
C. 提示 No matching distribution / DLL load failed：
   确认使用 64 位 Python 3.12、x64 Windows；DLL 错误按第三节检查微软运行库。如果装错 Python，停止中控后删除本项目 .venv-web 文件夹，再重新运行 setup-web.bat。
D. “未找到模拟器命令行工具”：
   手动填写 mumu-cli.exe / MuMuManager.exe / ldconsole.exe 的实际完整路径；旧版本没有该工具时需更新模拟器或使用手动 ADB 添加。
E. 模拟器启动超时 / ADB 无法连接：
   在模拟器中检查 ADB 开关，等待 Android 桌面完全加载；确认工具同目录有自带 ADB。使用手动 ADB 时，地址以模拟器实际显示为准，不套用 Mac 端口。
F. 游戏打不开 / 登录不到场景：
   检查是否安装官方客户端 com.netease.my，先手动完成账号登录、更新或验证，再重试。
G. 横屏就绪超时 / 识别位置不对：
   检查实际游戏画面是否横屏 16:9，建议 1280×720；关闭遮挡游戏的系统弹窗后重试。
H. 启动提示 8000 端口被占用：
   先检查是否已有一个中控窗口。确需换端口，在项目目录打开命令提示符运行：
   start-web.bat --port 8001
   然后访问 http://127.0.0.1:8001/，局域网地址也使用 8001。
I. 页面有旧内容：
   浏览器按 Ctrl+F5 强制刷新。更新 Python 后端代码需先停止任务和采集，再重启中控。

十二、关闭、备份与升级
1. 先停止任务并等待账号采集完成，再到中控命令行窗口按 Ctrl+C，关闭服务。
2. 日常数据保存在 .web-data：任务组合、实例信息、账号资料、日志等均在这里；迁移或升级前先备份整个文件夹。
3. 同一台 Windows 电脑升级时建议解压到新文件夹，在服务停止状态下迁移 .web-data，再运行新目录的 setup-web.bat；模拟器安装目录变化时重新导入。
4. 本安装包未包含 Mac 设备连接、角色采集记录、运行日志、访问令牌和 Python 虚拟环境。presets 仅包含清理过密钥的任务组合，不会自动恢复设备绑定。

十三、包内容及校验
- web：网页、接口和中控执行程序。
- agent、assets：原项目脚本及识别资源，包含当前工作目录新增任务资源。
- setup-web.bat / start-web.bat：Windows 安装 / 启动。
- docs：完整功能说明。
- presets\profiles.json：当前 7 套组合（密钥已清空）。
- PACKAGE_MANIFEST.json：包内每个项目文件的 SHA-256 与大小，可用于核对完整性。
- 本说明同时提供 TXT 和 HTML；HTML 可直接用浏览器打开阅读。
